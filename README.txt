SAVEWAY ICT — TPAD SMART V9

Host: Saveway ICT
Initial school configuration: Ngendalel Schools

V9 changes:
- Mobile-first TPAD interface
- PWA manifest
- Service worker/offline shell
- Android Chrome install prompt support
- App-style standalone display
- Saveway ICT host branding
- Ngendalel Schools tenant identity
- Existing TPAD targets, lesson observation, evidence, summary, workflow and analytics retained
- Existing multi-teacher/local records retained

IMPORTANT:
This package is a deployable PWA prototype, not yet a live internet-hosted service.
A permanent Chrome URL requires deployment to an HTTPS domain/hosting account.
A production multi-school service requires a secure server/database, authentication, role-based authorization, backups, audit logs and privacy/security controls.
The PWA can be installed from Android Chrome when served over HTTPS with a valid manifest; Chrome's PWA installation behavior is documented by web.dev.
